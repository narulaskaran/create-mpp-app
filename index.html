CLI flow

Where the CLI fits today

The original scaffold CLI is still in this repo. Phase 2 will switch it from local wallet generation to a hosted provisioning call against this deployment. 

npx create-mpp-app my-api

# current repo-local development
npm install
npm run dev -- my-api

Provisioning API

POST /api/provision

Creates an Ethereum wallet through Privy, exports the private key once, and returns the wallet material for the CLI flow.

Response

One-time wallet payload

{
  "walletId": "wallet_123",
  "address": "0xabc...",
  "privateKey": "0xdef...",
  "chainType": "ethereum",
  "warning": "Store this private key securely. It will not be shown again."
}

Deployment

Vercel env vars

Configure these before the hosted flow is usable:

PRIVY_APP_ID=
PRIVY_APP_SECRET=
PRIVY_API_BASE_URL=https://api.privy.io/v1
PRIVY_AUTHORIZATION_KEY_PUBLIC_KEY=
PRIVY_AUTHORIZATION_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----
